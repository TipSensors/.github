## TipToTip

**Can wingtip sensors tell you which way to turn?**

Sensor pods on both wingtips of a glider measure temperature, airflow angle,
pressure and motion 50 times a second, to test whether the difference between
the two tips shows which side the lift is on. An open research project: the
firmware, documents, flight data and CAD are all published.

- Code and documents: [TipSensors/tiptotip](https://github.com/TipSensors/tiptotip)
- Results, flight data, CAD and the talk: [tiptotip.org](https://tiptotip.org)
- Contact: Matt@TipToTip.org

Experimental, not certified for aircraft use.
